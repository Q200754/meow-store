# MEOW STUDIO — Minimal Pastel Streetwear Fashion Store

เว็บไซต์ร้านเสื้อผ้าออนไลน์สไตล์ Minimal Fashion Store ในโทนสีชมพูพาสเทล ขาว และเทาอ่อน สำหรับแบรนด์เสื้อผ้าแนว Streetwear ร่วมสมัย ออกแบบและพัฒนาเพื่อตอบโจทย์พฤติกรรมลูกค้าที่ช้อปปิ้งผ่านโทรศัพท์มือถือและสั่งซื้อผ่าน **Instagram Direct Message (DM)** โดยไม่ต้องผ่านระบบสมัครสมาชิก ตะกร้าสินค้า หรือชำระเงินที่ซับซ้อน

---

## ✨ จุดเด่นและการออกแบบ (Key Features)

### 1. สุนทรียศาสตร์และดีไซน์ (Design Aesthetics)
- **Palette โทนสี:** สีชมพูพาสเทล (`#FDE8ED`, `#F7B5C5`), สีขาวคลีน (`#FFFFFF`), สีเทาอ่อน (`#FAFAFB`, `#F4F4F6`) ตัดขอบด้วยสีดำสตรีทแวร์ (`#121316`)
- **Typography:** ฟอนต์โมเดิร์น `Plus Jakarta Sans` ผสมผสานภาษาไทยด้วย `Prompt` พร้อมตัวเลขอารมณ์เทคนิค `Space Mono`
- **Mobile-first & Fully Responsive:** รองรับการใช้งานสมบูรณ์แบบบน iPhone, Android, iPad/Tablet และ Desktop
- **Editorial Fashion Visuals:** แบนเนอร์ขนาดใหญ่, การจัดวางสไตล์ Lookbook, ป้าย New Drop, Hover zoom และการสลับมุมมองภาพสินค้า

### 2. ระบบสั่งซื้อผ่าน Instagram DM (Instagram Order Flow)
- **ไม่ต้องสมัครสมาชิก หรือเข้าสู่ระบบ:** ลูกค้าเปิดดูสินค้าได้ทันที
- **Mobile Screenshot Preview Card:** มีการ์ดจัดวางข้อมูลที่ออกแบบมาสำหรับการ "แคปหน้าจอ" บนมือถือโดยเฉพาะ แสดงรูปสินค้า รหัสสินค้า (SKU) ชื่อสินค้า สีและไซซ์ที่เลือก ราคา และชื่อร้านไว้อย่างชัดเจน
- **ปุ่ม "สั่งซื้อผ่าน Instagram DM":**
  1. สร้างข้อความสั่งซื้อที่ฟอร์แมตเรียบร้อย เช่น:
     ```text
     สวัสดีค่ะ สนใจสั่งซื้อสินค้าจาก MEOW STUDIO ✨
     - รหัสสินค้า: MW-HD-01
     - ชื่อสินค้า: Pastel Blush Boxy Hoodie
     - ไซซ์: XL
     - สี: Heather Grey
     - ราคา: ฿1,890
     (สอบถามสต็อกพร้อมส่ง และเลขบัญชีสำหรับโอนเงินค่ะ 🌸)
     ```
  2. คัดลอกลงใน Clipboard อัตโนมัติพร้อมแจ้งเตือนแบบ Toast
  3. เปิดหน้า Instagram ของร้านค้าทันที เพื่อให้ลูกค้ากดวาง (Paste) ส่งแชตได้รวดเร็ว
- **แสดงบัญชี Instagram ของร้านชัดเจน** ทั้งใน Header, Footer และปุ่มลอยสำหรับมือถือ

### 3. ระบบจัดการร้านค้าหลังบ้าน (Admin Portal)
- ซ่อนและป้องกันด้วยรหัสผ่าน PIN **(รหัส PIN ค่าเริ่มต้น: `8888`)**
- เข้าถึงได้จากลิงก์ท้ายเว็บไซต์ (Footer) หรือต่อท้าย URL ด้วย `?admin=1`
- **ฟังก์ชันผู้ดูแลระบบ:**
  - เพิ่มสินค้าใหม่ (Add Product) พร้อมระบุรหัส SKU, ชื่อ, หมวดหมู่, ราคา, ราคาเดิม, ไซซ์, สี (HEX), ลิงก์รูปหลายมุม, และรายละเอียดเนื้อผ้า
  - แก้ไขสินค้า (Edit Product)
  - ลบสินค้า (Delete Product)
  - ตั้งค่าร้านค้า (Store Settings): เปลี่ยนชื่อร้าน, เปลี่ยนชื่อบัญชี Instagram, ข้อความแถบประกาศด้านบน, สกุลเงิน, และเปลี่ยนรหัส PIN
  - รีเซ็ตข้อมูลสินค้าตัวอย่าง (Reset Demo Data)
  - ข้อมูลทั้งหมดบันทึกใน `localStorage` ของเบราว์เซอร์ ไม่สูญหายเมื่อรีเฟรชหน้าเว็บ

## 🚀 วิธีการเปิดใช้งาน (Getting Started)

### ทางเลือกที่ 1: รันผ่าน Local Server (แนะนำ)
เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์:
```bash
npm start
# หรือ
npx serve . -l 3000
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

### ทางเลือกที่ 2: ดับเบิลคลิกเปิดไฟล์โดยตรง
สามารถดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเบราว์เซอร์ใดก็ได้ทันที (ไม่ต้องติดตั้งโปรแกรมเสริม)
